📘 PRD — FieldFlux AgentKit: Social Media Tools
1. Executive Summary

Purpose:
Enable Felix to autonomously create, schedule, and publish social media content across platforms (Facebook, Instagram, Threads, LinkedIn, X/Twitter).

Core Idea:
Felix becomes the multi-channel content director — generating posts, adapting tone per platform, optimizing timing, and learning which content drives engagement.

Scope:

AI content generation & compliance checks

Unified posting/scheduling engine

Cross-platform performance tracking

Adaptive timing & tone adjustments via LearningLoop feedback

Outcome:
Field service owners maintain an active, optimized social presence — without touching calendars or post queues.

2. Goals & Success Metrics
Goal	Metric
Reduce manual content creation	≥ 80% of posts generated by Felix
Improve engagement	+25% average engagement vs. baseline
Increase posting consistency	≥ 3 posts/week average cadence
Real-time observability	100% posts emit LearningLoop telemetry
Adaptive optimization	Auto-adjust timing/tone after 2 cycles
3. Core Architecture
User Intent / Schedule
  ↓

4. Functional Overview
Function	Description	Trigger
Generate Post Copy	Create branded content via LLM	User prompt or automation
Publish Post	Post immediately to one/multiple platforms	User command or schedule
Schedule Campaign	Plan multi-day/multi-platform posts	Seasonal or weekly automation
Performance Monitoring	Fetch engagement metrics, detect trends	Post-publish polling
Adaptive Optimization	Modify tone/timing based on LearningLoop	Continuous learning cycle
5. Detailed Tool Specifications
5.1 generate_post_copy

Purpose: Create platform-specific, brand-aligned post content.

Inputs

{
  "topic": "HVAC fall maintenance",
  "tone": "friendly",
  "platforms": ["facebook", "instagram"],
  "goal": "engagement",
  "media_type": "image"
}


Outputs

{
  "drafts": [
    { "platform": "facebook", "content": "🍂 Keep cozy this fall..." },
    { "platform": "instagram", "content": "Fall check-ups = fewer breakdowns!" }
  ]
}


Features

Multi-platform adaptation (length, hashtags)

Compliance check (no restricted claims)

Keyword enrichment via local SEO data

Telemetry

Content generation latency

Sentiment / tone classification

Predicted engagement (via LLM eval)

5.2 publish_post

Purpose: Push prepared content to chosen platforms.

Inputs

{
  "platforms": ["facebook", "instagram"],
  "content": "🍂 Fall tune-up special!",
  "media_urls": ["https://cdn.fieldflux.ai/img/fall.jpg"],
  "schedule_time": "2025-10-27T14:00:00Z"
}


Outputs

{
  "status": "success",
  "platform_results": [
    { "platform": "facebook", "post_id": "fb_8234" },
    { "platform": "instagram", "post_id": "ig_3920" }
  ]
}


Integrations:
Meta Graph API, X API, LinkedIn Marketing API

Telemetry

{
  "tool": "publish_post",
  "metrics": { "delivery_success": true, "engagement_predicted": 0.78 }
}

5.3 schedule_campaign

Purpose: Manage sequences of posts (campaigns).

Inputs

{
  "campaign_name": "Winter Prep Series",
  "posts": [
    { "day_offset": 0, "topic": "filter change reminder" },
    { "day_offset": 3, "topic": "energy efficiency tips" }
  ],
  "platforms": ["facebook", "linkedin"]
}


Outputs

{
  "campaign_id": "cmp_942",
  "posts_scheduled": 2
}


LearningLoop Metrics

Optimal posting windows (time-of-day)

Platform engagement differentials

Hashtag / keyword performance

5.4 fetch_performance

Purpose: Collect engagement stats for published posts.
Outputs

{
  "post_id": "fb_8234",
  "likes": 42,
  "comments": 8,
  "shares": 5,
  "engagement_rate": 0.091
}


Telemetry: Engagement rate deltas → feeds LearningLoop evaluators.

11. Risks & Mitigations
Risk	Mitigation
API quota / rate limits	Queue + backoff scheduler
Post content flagged by platform	LLM moderation filter + retry
Low engagement cold start	Use LearningLoop global baseline heuristics
Missed schedule from API error	Retry policy + alert UI
